Query 001：る結尾能否直接判為一段動詞？

狀態：已執行。這是 LLM 為第一階段驗收設計的試查問題，不是冒稱使用者曾提出的問題。

問題

「帰る」與「食べる」都符合初學者可能聯想到的一段動詞外觀，可以只靠字尾判為一段嗎？兩者各屬哪一類？食べる的ます形是什麼？如果來源出現 tebe-masu，應如何處理？

實際查詢方式

目前對話中的 LLM 先讀取 Wiki 索引，再讀取 分類頁、帰る、食べる、基本規則及 證據登錄，依下列已核對內容回答。

這次沒有連網補查，也沒有呼叫獨立 LLM API。讀取清單、內容雜湊與工具命令另存於同名 JSON 紀錄。

回答

不能只靠這個字尾外觀判定。Wiki 的 R-CLASS-02 提醒，-iru／-eru 結尾的動詞可能是一段，也可能是五段；應連同單字記住分類。

動詞分類本次依據
帰る（かえる）五段／Group 1S01 的五段例詞列出帰る；S05 也把かえる放在 Group 1
食べる（たべる）一段／Group 2S01 的 Group 2 範例與 S05 的 Group 2 區塊一致

食べる的ます形是 食べます（たべます）：依 R-G2-01 去掉末尾る，再接ます。

S01 的 tebe-masu 已被標記為來源疑點 ISSUE-S01-001。Wiki 依 S01 的變化規則與 S05 的たべます採用正確讀音，保留原始快照並另外記錄採用理由，沒有改寫原文。

可追溯依據

  • R-CLASS-02／E-KAERU：分類頁、帰る頁；S01 文字第 42、87～88 行，S05 第 18、31～36 行。
  • R-G2-01／E-TABERU：基本規則、食べる頁；S01 第 42～60 行，S05 第 85、98～103 行。
  • 來源問題紀錄、精確證據登錄。

界線

這個回答只涵蓋已整理的兩個詞及規則，不能作為任意動詞的自動分類器。帰る的四形本階段未整理，不由這次回答補寫。
