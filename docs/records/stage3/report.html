HTML 教學成果、檢查與反思

狀態：本機教學成果完成；使用者明確選擇暫不發布。此報告記錄實際執行與測試，不把本機預覽當成公開網址。

成果

主簡報共16頁，依已執行的Wiki教學查詢編排。CSS、JavaScript與示範資料嵌入主HTML，可離線直接開啟。其他Wiki閱讀頁及證據入口放在同一個presentation資料夾。

每頁可展開Wiki依據；內容映射記錄頁碼、規則、Wiki頁及原始來源編號。動詞示範僅支援16個已核對詞、4種形式，共64種組合。六題練習涵蓋分類、ます、ない、て、た與来ない讀音，附理由及重作。

實際失敗與修正

  1. HTML生成程式的兩個て形表格字面值多了括號，被Python語法檢查攔下。檢視並修正兩處，先通過語法檢查，再成功生成HTML；沒有把這件事寫成文法規則錯誤。
  2. 第一輪瀏覽功能測試通過，但截圖顯示側欄編號會被長標題擠換行。修正CSS固定編號寬度，縮短第13頁標題，再跑97項測試並重拍截圖。
  3. 例外頁「見える結尾」的用字可能被讀成另一個日語例詞；改成「只因以『える』結尾」，保存修訂前查詢輸入並重跑Wiki檢查。沒有改變分類答案。
  4. 測試工具最新版本要求Node20，核對官方版本資訊後改用支援現有Node18的1.55.1；Chromium下載首次逾時後由安裝器換鏡像成功。工具只放/tmp。
  5. 本機預覽遇沙箱localhost限制，改在可存取的本機執行環境啟動127.0.0.1預覽，確認HTTP200。未對外發布；最終交付直接開啟本機HTML即可。

原始執行事件見 execution.jsonl。

反思

這次生成節點有程式語法問題，證據鏈有一次行號定位問題；瀏覽功能測試全數通過後，仍由截圖發現排版問題。不能把這些都合併稱為日語文法錯誤，也不能據少量執行推論長期錯誤率。

因此將來源／表格／引用定位檢查放在教學生成前；將生成程式語法檢查放在HTML輸出前；保留功能測試後的截圖檢視。最終流程有明確返回位置：證據錯回定位、語義錯回Wiki、生成語法錯回程式、排版錯回CSS。這些修改反映實際執行，不只是概念流程圖。

限制與重跑

只測試Chromium與模擬手機尺寸，沒有測試其他瀏覽器引擎或實體手機；這也不是完整無障礙稽核或日語教師審核。網站沒有登入、雲端資料或任意單字自動分類。

本次測試工具在/tmp，可於相同環境重跑（使用新報告檔名）：

PLAYWRIGHT_MODULE=/tmp/verb-wiki-browser/node_modules/playwright PLAYWRIGHT_BROWSERS_PATH=/tmp/verb-wiki-browsers node scripts/browser_check.cjs records/stage3/browser-rerun.json

網站本身無需Playwright。其他電腦若要重跑瀏覽測試，需另備對應工具；一般閱讀只需瀏覽器。
