日語動詞變化入門

從動詞分類到基本活用。學過五十音，就從一個熟悉的動詞開始。

食べる
食べます

藍色：保留部分紅色＋底線：變化部分

這次先學三件事：認出動詞類別、查用四種形式、記住主要例外。

以讀音理解規則，再看漢字寫法。標色是教學切分，不一律等同嚴格文法的語幹。

先認識辭書形與四形

辭書形是查字典的起點；同一個動詞，依表達需要改變形式。

形式食べる的例子先理解的功能
辭書形たべる查字典；普通形非過去肯定
ます形たべます禮貌非過去肯定
ない形たべない普通形非過去否定
て形たべて接續其他表達
た形たべた入門先理解為普通形過去肯定
て形不等於現在式；た形在其他句型也可能有不同功能。本課先學基本變化。

三類動詞，先分清楚

分類決定規則。學單字時，把讀音、意思與類別一起記。

類別教材標示例子
五段動詞Group 1読む（よむ）、帰る（かえる）
一段動詞Group 2食べる（たべる）、起きる（おきる）
變格動詞Group 3する、来る（くる）
い段／え段音＋る是分類提示，不能保證是一段。帰る仍是五段。

04 / 16

ます形：五段改い段

最後的う段音改成同一行的い段音，再接ます。

末尾換成例子
ういます買う（かう） → 買います（かいます）
つちます待つ（まつ） → 待ちます（まちます）
るります帰る（かえる） → 帰ります（かえります）
ぬにます死ぬ（しぬ） → 死にます（しにます）
ぶびます遊ぶ（あそぶ） → 遊びます（あそびます）
むみます読む（よむ） → 読みます（よみます）
くきます書く（かく） → 書きます（かきます）
ぐぎます泳ぐ（およぐ） → 泳ぎます（およぎます）
すします話す（はなす） → 話します（はなします）

05 / 16

ます形：一段與變格

一段去掉る；する、来る各自記。

類別方法例子
一段去る＋ます食べる（たべる） → 食べます（たべます）
變格分別記憶する（する） → します（します）
變格留意讀音来る（くる） → 来ます（きます）

ます是禮貌形式，不是固定的「正在做」

わたしは毎日勉強します。

我每天讀書／學習。ます形也可用來描述狀態與未來安排。

例句出自 S02；中文為教學譯義。

06 / 16

ない形：五段通常改あ段

通常改成同一行的あ段音，再接ない。う結尾要改成わない。

末尾換成例子
うわない買う（かう） → 買わない（かわない）
つたない待つ（まつ） → 待たない（またない）
るらない帰る（かえる） → 帰らない（かえらない）
ぬなない死ぬ（しぬ） → 死なない（しなない）
ぶばない遊ぶ（あそぶ） → 遊ばない（あそばない）
むまない読む（よむ） → 読まない（よまない）
くかない書く（かく） → 書かない（かかない）
ぐがない泳ぐ（およぐ） → 泳がない（およがない）
すさない話す（はなす） → 話さない（はなさない）
買う → 買わない（かわない）。不要把う換成あ再接ない。

07 / 16

ない形：一段、變格與ある

先分類，再處理需要另外記憶的形式。

動詞ない形提醒
食べる（たべる）食べない（たべない）一段去る＋ない
するしない變格
来る（くる）来ない（こない）讀音變成こ
あるない五段，否定有例外
ある的否定是ない，分類仍是五段；不能因某個形式特殊，就把整個動詞改列變格。

08 / 16

て形：把五段字尾分成五組

先找到辭書形最後一個假名，再套用同一組的變化。

末尾換成例子
う・つ・るってかう→かって；まつ→まって；かえる→かえって
む・ぶ・ぬんでよむ→よんで；あそぶ→あそんで；しぬ→しんで
くいてかく→かいて
ぐいでおよぐ→およいで
すしてはなす→はなして
這張表適用於五段動詞；一段與變格看下一頁。行く也要另記。

09 / 16

て形：一段、變格與行く

一段去る＋て；する、来る、行く分別核對。

動詞て形提醒
食べる（たべる）食べて（たべて）一段
するして變格
来る（くる）来て（きて）留意き
行く（いく）行って（いって）五段，但此形有例外
想知道音便名稱？

って組可對照促音便，んで組可對照撥音便，く／ぐ的い變化可對照イ音便。す→して不列入這三種。名稱作輔助，先記分組與例詞。

立ってください。

請站起來。「てください」構成請求；例句出自 S04。

10 / 16

た形：て換た，で換だ

沿用て形的分組與例外，就能減少重複記憶。

辭書形て形讀音た形讀音
買うかってかった
読むよんでよんだ
書くかいてかいた
泳ぐおよいでおよいだ
話すはなしてはなした
行くいっていった
食べるたべてたべた
するしてした
来るきてきた
入門先理解為普通形過去肯定。特別留意んで→んだ、いで→いだ。

最容易混淆的四件事

把錯誤與正確內容放在一起比較，找出規則的邊界。

情況錯誤示範正確內容
字尾分類帰る是一段帰る是五段；帰ります、帰って
う結尾否定かあない買わない（かわない）
ある否定あらないない
行く的て／た行いて／行いた行って／行った
再記一個讀音：来ない是こない。特殊變化與分類要分開判斷。

六題小練習

先自己選，再檢查答案。答錯時對照理由，回到相關規則重看。

帰る屬於哪一類？

書く的ます形讀音？

買う的ない形讀音？

行く的て形讀音？

泳ぐ的た形讀音？

来ない要怎麼讀？

查看答案與原因
  1. 五段。える結尾不保證一段；帰る是五段。
  2. かきます。五段く改為き，再接ます。
  3. かわない。う結尾需改為わない。
  4. いって。行く仍是五段，但て形另記いって。
  5. およいだ。て形およいで，で換成だ。
  6. こない。来る的ない形讀作こない。

  • R-TA-01：て形末尾て→た、で→だ；含行く例外

把順序記住，再練一次

遇到一個動詞，先問自己這三個問題。

  1. 辭書形、讀音、意思是什麼？
  2. 是哪一類？有沒有分類或形式上的例外？
  3. 現在要用ます、ない、て，還是た形？
先用熟悉動詞練習，再加入查過類別的新詞。回到第13頁比較行く與書く、第14頁重做練習。
